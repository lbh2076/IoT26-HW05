# IoT26-HW05: Getting Started with Home Assistant on Raspberry Pi

## Objective
Show you how to get started with Home Assistant on Raspberry Pi and build a simple example to get you started with home automation. 

## Configuration Code
* **`configuration.yaml` `command_line.yaml`**: Home Assistant의 설정 파일입니다. `command_line` 통합구성요소를 활용하여, 스위치를 조작할 때 터미널 명령어(`gpioset`, `gpioget`, `pkill`)가 백그라운드에서 실행되며 GPIO 핀을 제어하도록 구성했습니다.

## Results
Home Assistant 엔티티 추가 화면 및 대시보드에서 스위치로 LED를 제어하는 시연 영상은 본 저장소에 업로드된 파일을 확인해 주세요.
